# Politique de confidentialité

Cette politique de confidentialité décrit le traitement des informations liées au site web GuineaGood.

GuineaGood ne collecte aucune information personnelle ni aucune donnée d'utilisation sur ce site. Le site ne demande ni n'enregistre d'identité, d'adresse e-mail, de localisation, de données de navigation ou de préférences utilisateur.

Seule une information est enregistrée localement dans le navigateur : la langue sélectionnée pour l'affichage du site. Cette information est stockée uniquement pour conserver la préférence de langue de l'utilisateur et n'est utilisée que pour afficher le site dans la langue choisie.

## 1. Aucune donnée collectée

Le site ne collecte pas :

- aucun nom, prénom ou identifiant ;
- aucune adresse e-mail ;
- aucune donnée de géolocalisation ;
- aucune donnée de navigation ou de comportement ;
- aucune donnée sur l'appareil ou le système d'exploitation ;
- aucune donnée analytique, publicitaire ou marketing.

## 2. Langue utilisée

La seule information stockée localement est la langue choisie par l'utilisateur (français ou anglais). Cette préférence est enregistrée dans le stockage local du navigateur.

Cette information :

- est utilisée uniquement pour afficher le site dans la langue souhaitée ;
- n'est pas transmise à un serveur tiers ;
- n'est pas utilisée à des fins de profilage ni de marketing ;
- n'est pas conservée au-delà du besoin d'affichage du site.

## 3. Aucun usage des informations

Aucune information n'est utilisées pour :

- suivre les utilisateurs ;
- analyser le comportement ;
- proposer des publicités ;
- vendre ou partager des données.

## 4. Sécurité

Comme aucune donnée personnelle n'est collectée, il n'y a pas de données sensibles à stocker ou à protéger sur le site.

## 5. Modifications

Cette politique peut être mise à jour uniquement pour refléter un changement de fonctionnement du site. Aucune donnée supplémentaire ne sera collectée sans mise à jour claire de cette politique.
