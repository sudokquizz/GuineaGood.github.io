# Privacy Policy

This privacy policy describes how information is handled on the GuineaGood website.

GuineaGood does not collect any personal information or usage data on this website. The site does not ask for or store names, email addresses, locations, browsing data, or any other user data.

Only one piece of information is stored locally in the browser: the language selected for displaying the site. This information is kept only to remember the user's language preference and is used only to display the site in the chosen language.

## 1. No data collected

The site does not collect:

- any first or last name or identifier;
- any email address;
- any geolocation data;
- any browsing or behavioral data;
- any device or operating system data;
- any analytics, advertising, or marketing data.

## 2. Language preference

The only information stored locally is the chosen language (French or English). This preference is saved in the browser's local storage.

This information:

- is used only to display the site in the selected language;
- is not transmitted to any third-party server;
- is not used for profiling or marketing;
- is not retained beyond the needs of displaying the site.

## 3. No data use

No information is used to:

- track users;
- analyze behavior;
- display ads;
- sell or share data.

## 4. Security

Because no personal data is collected, there are no sensitive data records to store or protect on the site.

## 5. Changes

This policy may be updated only to reflect a change in how the site works. No additional data will be collected without a clear update to this policy.
